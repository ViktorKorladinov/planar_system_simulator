# Tile Glider

This project contains implementation for simulator used for experiments on planar transport systems.

## Authors
- Viktor Emil Korladinov
- Vojtěch Mička

## Content

This repository contains the following directories:
- `app` - directory with pages
- `components` - directory with components for user interface
- `public` - directory with icons
- `styles` - directory with styles
- `utils` - directory with utilities

## Dependencies

- To run this project locally, you need to have [Node.js](https://nodejs.org/) installed.
- Dependencies can be installed with the following command: ```npm install```

## How to Run

1. Set environment variable `NEXT_PUBLIC_API_URL` as the URL for the REST API (e.g. http://localhost:8000/api/v1).
2. Use the following command to start the development server: ```npm run dev```
3. Open [http://localhost:3000/](http://localhost:3000/) in your browser.
